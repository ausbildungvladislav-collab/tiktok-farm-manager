TikTok Farm Manager

Desktop content management and publishing tool

About

TikTok Farm Manager is a desktop application for managing user-owned TikTok accounts and publishing user-created video content through TikTok's official developer APIs.

Users connect their TikTok account through TikTok Login Kit and explicitly authorize requested permissions. The application uses the Content Posting API for authorized publishing.
